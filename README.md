# Bank Account System

Консольное приложение на Java для имитации банковских операций, управления счетами и перевода средств между ними. Проект разработан в рамках учебного задания.

## Основной функционал
- **Иерархия счетов**:
  - `DebitAccount` — стандартный дебетовый счет с поддержкой пополнения и снятия.
  - `CreditAccount` — кредитный счет, допускающий уход в минус в пределах установленного лимита.
  - `DepositAccount` — накопительный счет с ограничением на операции.
- **Сервисный слой (`BankService`)**:
  - Ведение реестра счетов.
  - Безопасный перевод средств между счетами по их идентификаторам с проверкой статуса (активен/закрыт) и достаточности баланса.
- **Обработка исключений**: собственные иерархические исключения для контроля ошибок (`InsufficientFundsException`, `AccountClosedException`, `AccountNotFoundException`).

## Технологический стек
- **Java 17+**
- **Maven** (сборка проекта и управление зависимостями)
- **JUnit 5** (модульное тестирование)
